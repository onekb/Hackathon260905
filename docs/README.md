# InferPool 项目文档

InferPool 是黑客松中的 AI 推理市场：卖家独立运行 Mock 节点，买家通过网页或统一 API 使用服务，Monad 测试网合约负责报价、资金托管、预算锁定和结算。平台负责链外路由、模拟计量及故障判责。

**当前：业务合约已部署并完成源码验证；本地双卖家链路和测试网 API 烟测通过；浏览器独立买家的资金准备及正常、失败、预算、缓存、主动取消共六种目标场景通过，八笔实际请求完成对账。** 网页 Key 生命周期已检查，未用该 Key 发请求；Monad 第二卖家、公网、浏览器钱包切换和断连/幂等仍未验收。前序 API 使用同一钱包，本次网页买卖双方不同。详情以 [开发进度与证据](progress.md) 为准。
