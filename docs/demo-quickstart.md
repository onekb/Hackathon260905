## 现场网页点击流程

1. 点击左侧 **“推理市场”** → 节点选择 **“Monad 演示节点”**（`seller-monad`）。不要临场改成自动匹配或新增卖家。
2. **本次预算：`0.001` MON；最多输出：`512`；取消勾选“模拟上下文缓存”。** 输入：

   > 用三个要点解释：链上托管如何保护买家的推理预算？

3. 点击一次 **“运行请求”**。先锁款，再输出；等待右侧 **“链上已确认”**。指出“实际费用”“已释放预算”，再点 **“查看结算交易”**。新单以现场账单为准，不把历史费用贴成新结果。
4. 点击 **“请求账单”**，选择故障单 **`c985df51-7600-43dc-8ac2-5a9fcf2b150f`**。确认费用 **0 MON**、释放 **0.001 MON**，明确这是先前已验证的故障单；不要点击运行去重造故障。
5. 回到两单对照或 PPT 收尾。正常费计入卖家**合约托管可用余额**，不是自动提现到外部钱包。
